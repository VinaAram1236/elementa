# ELEMENTA

An interactive periodic table for exploring elements, testing chemistry knowledge, and combining atoms in a simplified reaction lab.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## Features

- Explore all 118 elements with search and category filters
- View element facts, properties, and reference links
- Take generated quizzes with selectable lengths
- Combine common element pairs in the reaction lab
- Save favorites and progress in browser local storage
